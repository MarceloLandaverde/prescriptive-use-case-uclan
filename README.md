# prescriptive-use-case-uclan
Repository containing main code for a prescriptive use case which is to be presented at the UCLAN

# Content
In this repository you will find the following files:
- utils.py:
  This file contains all the needed functions to build the prescriptive analytics use case.
- app.py:
  This files contain the main code for a streamlit application. All the functions needed are retrieved from the utils.py file.
- mathematical-modeling.txt:
  This files contains the pseudo-mathematical modeling of the TSP. This is very helpful in cases where we want to add additional constraints, variables, parameters or similar.
